# HEATWISE Control Room

A what-if simulation of London heat-dome monitoring and control for SPCE0019 Project Simulation (UCL Centre for Systems Engineering).

Open the live page: https://sbegucl.github.io/heatwise/archive/v1/

- Data: ECA&D daily observations, London Heathrow (STAID 1860), May-September 1979-2023. Klein Tank, A.M.G. et al. (2002), Int. J. Climatol., 22, 1441-1453. https://www.ecad.eu
- Health model calibrated to the UKHSA Heat mortality monitoring report 2022 (London: 387 excess deaths).
- Teaching model: neighbourhood uplifts, group profiles, capacity and intervention effects are illustrative assumptions.
- The page runs entirely in the browser. It sends no data anywhere; notes and priorities stay in the viewer's own browser.
